# tatr

A Rust port of [tsoding/tatr](https://github.com/tsoding/tatr).

> Check tsoding's repo for tatr spec. All the files and spec matches with the original, so you can change between this and tsodings version without any changes. But this cmdline tool has a slightly different set of commands.

**Notice:** This is a personal tool built strictly for my own workflow. I do not intend to provide support, accept feature requests, or maintain this for other users. It is provided entirely as-is.
